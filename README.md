\# ✍️ Next Word Predictor using LSTM



A deep learning project that predicts the next words in a sentence using an LSTM neural network, with an interactive Streamlit web UI.



\## Features

\- LSTM model trained for next word prediction

\- Interactive Streamlit web app

\- Adjustable number of words to predict (1–20)



\## Tech Stack

\- Python, TensorFlow/Keras, Streamlit, NumPy



\## How to Run

pip install streamlit tensorflow numpy

python -m streamlit run app.py



\## Project Structure

\- app.py — Streamlit UI

\- lstm\_model.h5 — Trained LSTM model

\- tokenizer.pkl — Fitted tokenizer

\- max\_len.pkl — Max sequence length
